# 订单查询 Skill

## 何时使用
用户查询**自己的**订单、券、支付/退款/秒杀状态。

## 工具
`queryMyOrders(status?)` —— 查当前登录用户的订单。status 含义见 `references/order-status.md`；不传 status → 查全部。

## 流程
1. 用户说"我的订单/待支付/买过的券" → `queryMyOrders`（按需带 status，对照状态码表）。
2. 结合订单里的店铺/套餐信息回答；用户想进一步看店，可再走 shop skill。

## 护栏
- **只能查当前登录用户自己的订单**，不能查别人——订单是隐私数据，越界查询是严重违规。
- 订单 ID 为雪花 ID（长数字），展示时可用尾号/简称，不暴露完整内部 ID。
- 下单/支付/退款/取消均属写操作，**必须用户明确确认**后执行。

## 回答规则（Answer 阶段）
- 订单/券列表**完整呈现**：套餐名、金额、状态、下单时间，用列表逐条列出，不挑不删。
- 状态用中文表达（待支付/已支付/已核销/已取消/退款中/已退款），不暴露状态码与订单号全文。
- 金额如实展示（价格/实付），不四舍五入误导。
- 待支付订单可顺带提示"是否现在支付"（写操作，需用户确认后再调用）；退款进度如实按状态说明。
