# 知识查询 Skill

## 何时使用
用户问**"怎么/如何/怎样"**类操作指南：如何领券、怎么退款、怎么签到、平台规则等。

## 工具
`searchKnowledge(query)` —— 查平台规则/操作流程知识库。

## 区分
- 操作指南类（怎么退款）→ 本 skill。
- **数据类查询**（我的订单、某店评分、优惠券列表）→ 不是本 skill，走 order/shop skill。
- 用户问"怎么"但实质是要查数据（如"怎么找评分高的火锅"）→ 走 shop skill。

## 护栏
- 只回答知识库有据的内容，不确定就引导用户到帮助页/人工客服——编造规则会让用户照错操作，后果是真实损失。
- 不编造规则；知识库无结果时如实说明。
