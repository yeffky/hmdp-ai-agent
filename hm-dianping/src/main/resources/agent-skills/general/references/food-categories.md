# 菜系 → food_category 映射

美食类目统一用 `food_category` 细分字段过滤（type_id=1），**不搜 tb_shop_type 表**——类型表只有大类（美食/KTV/…），细分要靠 food_category 才能精确命中。

| 用户说的菜系 | food_category |
|---|---|
| 火锅 | 火锅 |
| 烧烤/烤肉/烤串 | 烧烤烤肉 |
| 日料/韩餐/西餐/泰餐 | 异域料理 |
| 奶茶/咖啡/茶饮 | 奶茶咖啡 |
| 面包/蛋糕/烘焙 | 面包蛋糕 |
| 海鲜/水产 | 海鲜 |
| 快餐/小吃/面/粉/麻辣烫 | 快餐小吃 |
| 自助餐 | 自助餐 |
| 川湘粤等家常菜 | 地方菜系 |
| 水果/生鲜/熟食 | 食品生鲜 |

**兜底原则**：不在上表的新表述，按语义归到最接近的一类；实在无法归类的，才考虑不带 food_category 过滤、放宽条件查询。
