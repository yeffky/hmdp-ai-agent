# 历史回溯 Skill

## 何时使用
用户引用**当前上下文窗口中不存在的历史对话**：如"上次你推荐的""之前聊过的""还记得我问过"。

## 工具
`searchHistory(keywords)` —— 按关键词检索当前用户的历史对话。

## 参数规则
- keywords 从用户消息提取**名词/实体/话题**，多个用空格分隔（如"火锅 推荐"）。
- 只搜当前登录用户自己的历史，不能跨用户——历史含个人隐私，越界搜索是严重违规。

## 流程
1. 判断确实是对历史对话的引用（而非当前问题）。
2. 提取关键词 → `searchHistory`。
3. 命中则基于历史继续回答；未命中则如实说明"没找到相关记录"。

## 护栏
- 不虚构历史；检索不到就说找不到——编造"上次说过的话"比不回答严重得多。
- 历史中的个人敏感信息不外泄。
